Appeal Form Automations

Project for: Altus Group

Problem

There were a large number of properties to be appealed and the company had to notify the assessor that they were going to be representing the client in the hearing. Despite how the notification forms for this process were in a standard format, that standard was different for each assessor and appeal type.

Filling out these forms was a time-consuming process and only became worse each year, as new business came in. The VP of Operations brought this project to me because an employee had shared concerns about the amount of appeal forms that needed to be completed for that jurisdiction that year. The consultant team needed a way to quickly fill out the forms for each of their properties with minimal human error.

Solution

I utilized Power Query in Excel to extract, transform, and load the data from the company's database to create a CSV to be used with the Evermap AutoMailMerge™ software. The Evermap software was used to fill out the PDF form and create a completed form for each listed property.

Then a Visual Basic macro was run to combine the resulting PDF with its associated supporting files. This was made to be handled by the use of a Windows batch (.bat) file to allow for non-technical employees to accomplish the task with the ease of clicking the file.

Challenges

PDF Form Limitations: I had to use Evermap AutoMailMerge™ because there is no way to accomplish a MailMerge on PDF files via VBA. This required integrating third-party software into the automation workflow.

Secure Execution: I had to create the batch script in order for this to be used by the consultant and only allow for them to run the automation without accidentally causing an issue with any of the files being stored on the AWS server. The batch file provided a controlled execution environment that prevented users from modifying or deleting critical files.

Result

The original task took the consultant and her team of 3 people 3 days (with overtime) to complete each year in the past. This was with about half the amount of appeals that would be done the year I was asked to create an automation.

Even with the doubled workload (over 300 forms), the result was that the entire project was completed in under 3 minutes by one person who only had to run the .bat file. The process is now able to be done by one team member, and with its simplicity, the team was able to more easily transfer the process to new team members.

Technologies Used

  • Excel
  • Power Query
  • Evermap AutoMailMerge™
  • VBA (Visual Basic for Applications)
  • Windows Batch Scripting
  • AWS (file storage)
