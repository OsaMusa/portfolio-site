Report Generator

Project for: Altus Group

Problem

When appealing the values of parcels, consultants need to provide their evidence in a format that explains their points. This is done in the form of a narrative that includes the counter values and the methodologies behind how they came to them.

The process of creating these narratives was made more repeatable by having the calculations done in Excel workbooks that would have the results in a format that was ready to be copied and pasted into a Word document. Then, the consultant would make the necessary edits based on the factors they felt applied to the case.

The resulting evidence report could be created by an experienced consultant in about 1.5 hours. With the company growing, this was unsustainable and difficult to train new consultants on. The company needed a way to reduce the time taken to create these evidence reports that was simple enough for new hires to quickly complete.

Solution

Since the narratives were created using Microsoft Office applications, I developed a VBA macro to automate the report generation process.

The macro was embedded in Excel workbooks that contained a checklist of narrative sections consultants could select for inclusion. Before distribution, I integrated the macro into each Excel file so consultants had the automation readily available.

When a consultant ran the macro, it would open a Word document template and populate the narrative by searching for placeholder tags and replacing them with the corresponding data from the Excel workbook. The macro handled not just text, but also charts, images, tables, and other visual elements, maintaining proper formatting throughout.

Additionally, the macro could generate a PDF version of the completed evidence report and automatically combine it with any supporting documentation files.

Result

The consultants became able to create evidence reports by simply deciding what parts of their Excel-based calculations they wanted to include, and then clicking the button to run the macro.

With this macro, the time needed to complete the process of transferring Excel calculations into an evidence report was dropped from 1.5 hours to 45 seconds. Furthermore, they were then able to more easily train novice consultants to create competent narratives in preparation for appeal hearings.

Technologies Used

  • Excel
  • Word
  • VBA (Visual Basic for Applications)
