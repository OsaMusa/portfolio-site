US Average Housing Prices by ZIP

Project for: Personal

Problem

In the United States, housing has become increasingly expensive. Understanding how home values have changed over time is critical for buyers, sellers, investors, and policymakers.

The idea for this project came from a real estate investor I knew who was familiar with someone who had created a heatmap of property values for the DFW area. I wanted to see if I could build something similar, but at a national scale, covering the entire United States rather than just one metroplex.

While Zillow provides extensive data on home values through their ZHVI (Zillow Home Value Index) dataset, the raw data is not easily accessible or visualizable for the average user. There was a need for an interactive tool that could help people explore and understand housing value trends across the country at a granular level, down to individual ZIP codes, over more than two decades of data.

Solution

I built a multi-page Streamlit web application that transformed Zillow's ZHVI dataset into an interactive visualization experience. The application featured:

Hierarchical Filtering System: Users could drill down from State → Metro Area → County → City → specific ZIP codes. The filters were synchronized across all pages using Streamlit's session state, so selections persisted as users navigated between visualizations.

Heat Map Visualization: Displayed property values geographically using pydeck and GeoJSON data. Users could toggle between 2D and 3D views, with colors representing value ranges (red-to-yellow gradient). The map highlighted the lowest, median, and highest valued ZIP codes in the selected area.

Historic Value Trends: Showed time-series line charts of home value changes with configurable timeframes (3 years, 5 years, 10 years, or maximum since 2000). Users could compare multiple ZIP codes simultaneously.

Data Pipeline: Created a data preparation script that processed the raw Zillow CSV data, filled missing months through interpolation, enriched city names using postal code lookups, and serialized everything into an efficient format for fast loading. The entire dataset was cached with a 12-hour TTL to optimize performance.

Challenges

Data Storage Optimization: The dataset was massive: 40,000+ ZIP codes with 20+ years of monthly data. Initially, I tried using Python's pickle format for serialization, but the file sizes were still too large for efficient loading. I researched alternative formats and learned about Apache Feather, which provided much better compression and faster read times. This required understanding the tradeoffs between different serialization formats and implementing the conversion pipeline.

Advanced Visualizations: While pydeck provided a Python wrapper for deck.gl (a JavaScript library for geospatial visualizations), getting the exact results I wanted required understanding how the underlying JavaScript library worked. I had to learn about GeoJSON layers, elevation scaling for 3D views, and color mapping to achieve the heatmap effect. This meant going beyond the Python documentation and diving into the deck.gl documentation to understand the capabilities and limitations of the visualization engine.

Deployment Constraints: The application was hosted on Streamlit Community Cloud, which had a significant limitation: the app went to sleep after a period of inactivity. When a visitor arrived at a sleeping app, they were shown a wake-up page and had to click a button to start the application. This created a less-than-ideal first impression, but it was a tradeoff of using free hosting for a data-intensive application.

Data Update Limitations: Due to Zillow's Terms of Service, the data could not be automatically scraped or gathered programmatically. The dataset had to be manually downloaded and processed, so the application displayed data through February 2024.

Result

The application visualized housing data for 40,000+ ZIP codes across 20+ years of Zillow data (January 2000 to February 2024). It was deployed on Streamlit Community Cloud, making it freely accessible to anyone interested in exploring housing market trends. The interactive nature allowed users to quickly identify value patterns in areas they were interested in, from broad metro-level trends down to specific neighborhoods.
